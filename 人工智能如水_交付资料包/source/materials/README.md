# 原始素材存放说明

本目录在**最终 ZIP 交付包**中包含全部原始 PNG 文件：

| 文件名 | 用途 |
|---|---|
| `hero-water-abstract.png` | Hero 区抽象水流背景。 |
| `logo-water-flow.png` | Header、Footer 与 favicon 标识。 |
| `logo-water-flow_original.png` | Logo 原始备份。 |
| `section-divider-wave.png` | 章节波浪分隔线。 |
| `card-bg-water-texture.png` | 卡片水纹背景。 |

由于静态网页项目的检查点不允许提交超过 1MB 的本地媒体，项目目录中的交付资料包可能不含上述二进制文件；请下载并解压最终的 `人工智能如水_交付资料包.zip` 取得完整原件。`SHA256SUMS.txt` 保留在此目录，用于核验完整 ZIP 中的关键文件。
