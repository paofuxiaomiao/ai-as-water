# 《人工智能如水》交付资料包

## 资料包用途

本资料包用于**离线保存、审阅、复现与二次开发**《人工智能如水》长文展示网页。它保留了原始输入、用户提供的参考截图、已有的设计构思、可追溯的生图提示词、静态视觉素材、关键页面源码、第一版页面快照、现有运行记录与本次收尾说明。

该资料包不是部署产物本身；若需运行网页，请在项目根目录执行 `pnpm install`（依赖未安装时）后运行 `pnpm dev`。若仅需审阅，请从本文档和 `01_提示词与素材清单.md` 开始阅读。

| 缺失项 | 缺失原因 | 可替代方案 |

## 部署目录与完整 ZIP 的差异

为满足静态网页项目的检查点限制，项目目录中的交付资料包会保留**文档、源码、清单、校验和与素材索引**，但不会重复存放大于 1MB 的原始 PNG。完整的原始 PNG、PDF、用户参考截图、源码与 Markdown 均保留在最终导出的 `人工智能如水_交付资料包.zip` 内；该 ZIP 是本次交付的**权威离线归档版本**。

在项目目录内离线查看时，请先阅读 `source/materials/README.md`；若需要原始 PNG 文件，请下载并解压最终 ZIP。该处理不会改变网页运行时使用的托管图片 URL。
