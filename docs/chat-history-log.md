# 《人工智能如水》网页项目与交互迭代演变记录

本文档梳理了基于 OpenAI 参考网页（Harness Engineering 文章页）风格，将演讲稿《人工智能如水》转换为高质量互动长文网页的全过程，包括设计决策、功能演变、模式切换实现以及 Skill 打包细节。

---

## 一、 项目背景与核心目标

- **参考对象**：OpenAI 官方博客风格 [1]。
- **输入材料**：《演讲稿(1).pdf》全文（面向小学教师与大众的 AI 智能体认知开场稿）。
- **交付目标**：打造一个具备极高排版美感、支持多种视觉风格与字体切换、兼具桌面与大屏投影模式的长文阅读展示网页。

---

## 二、 核心迭代与演变历程

### 1. 第一阶段：首版设计与风格建立
- **视觉基调**：采用纯白底、深黑字、大量留白与极致排版，辅以淡雅水墨/流动感抽象背景（Hero 区域）。
- **组件布局**：左侧固定目录导航（支持滚动高亮）、顶部阅读进度条、大号衬线标题（Noto Serif SC）、蓝色左线引用卡片。
- **内容呈现**：将 PDF 演讲稿结构化拆分为 8 个核心章节，加入名词解释卡片、Prompt 示例、课堂案例和分隔引用块。

### 2. 第二阶段：贴近 OpenAI 原版布局
- **用户反馈**：希望更贴近 OpenAI 原文页的纯净度。
- **改进措施**：优化工具栏与文章双栏布局，去掉部分繁复装饰，使整体显得更加克制、学术、干净。

### 3. 第三阶段：多模式切换与独立字体控制
- **功能扩充**：为了兼顾美观与个性化阅读需求，引入了多维度切换控制：
  1. **视觉模式切换**：支持「极简」、「装饰」、「编辑」三种风格无缝循环或独立点选。
  2. **字体切换**：独立提供「衬线体」与「无衬线体」切换按钮，可与任意视觉模式自由组合。
  3. **大屏/演示模式**：提供大屏模式切换，支持全屏沉浸式阅读与投影演示。

### 4. 第四阶段：全屏大屏模式与第一版风格还原
- **需求对齐**：用户明确指出希望大屏模式呈现最初交付的“第一版”完整风貌（包含衬线大标题、蓝色渐变章节分隔线、左侧蓝色竖线目录、优雅的诗句引言等）。
- **技术实现**：在代码中完美固化了第一版的排版样式，使大屏/演示模式一键切换即呈现第一版的精致质感。

---

## 三、 功能模块总览

| 模块名称 | 功能说明 | 交互方式 |
| :--- | :--- | :--- |
| **顶部工具栏** | 集中管理视觉模式、字体选择与大屏切换 | 点击对应按钮实时响应 |
| **视觉模式组** | 切换“极简”、“装饰”、“编辑”三种设计皮肤 | 独立按钮点选高亮 |
| **字体切换组** | 切换 Noto Serif SC 衬线体与 Noto Sans SC 无衬线体 | 独立按钮点选高亮 |
| **大屏模式按钮** | 一键进入全屏沉浸模式，复现第一版完整排版 | 点击切换，支持退出 |
| **左侧侧边栏** | 展示 8 个章节的实时目录，跟随滚动自动高亮 | 点击标题平滑滚动跳转 |
| **分享与导出** | 提供一键复制链接/分享提示 | 点击触发通知反馈 |

## 四、 导出资产与 Skill 打包清单

1. **设计说明文档**：
   - `docs/exports/design-ideas.md`：核心设计构思与哲学。
   - `docs/exports/modes-design-spec.md`：五种模式及图片插入规范的详细技术规格书。
   - `docs/exports/image-prompts.md`：生图提示词集合。
2. **可复用 Skill**：
   - `docs/skill/`：`article-showcase` 技能包，包含 `SKILL.md`、参考规范及完整组件模板，支持未来任意长文快速转化为该风格网页。
3. **视觉素材与原始文档**：
   - `docs/assets/`：包含 Hero 抽象背景、Logo、波浪分隔线及卡片纹理。
   - `docs/演讲稿(1).pdf`：原始输入材料。

## 五、 总结

本项目通过精细的排版设计、现代化的前端组件以及灵活的模式切换系统，成功将一份严肃的演讲稿转化为极具专业感与观赏性的数字长文作品，并通过 Skill 打包实现了资产的可复用性。
